# Тренажёр оператора 112 и диспетчера ДДС

Учебное веб-приложение для класса: ИИ-заявитель звонит на место оператора 112, карточка уходит на места диспетчеров ДДС, бригады докладывают по телефону, система проверяет действия по нормативам, преподаватель видит весь класс и подтверждает оценку.

> Работа в процессе. Документация, архитектура и инструкция по офлайн-установке появятся в `docs/`.

## Быстрый запуск (разработка)

Нужны Node.js 22+, pnpm 9+, Docker.

```bash
cp .env.example .env
pnpm install
pnpm db:up          # PostgreSQL в Docker на порту 5442
pnpm db:migrate
pnpm db:seed        # демо-учётки и справочники
pnpm dev            # http://localhost:3100
```

Без настроек модели приложение работает в режиме заглушки: ИИ отвечает шаблонно, сеть не нужна. Адреса моделей задаются в `.env` (`LLM_*`, `STT_*`, `TTS_*`) — подходит любой сервер с OpenAI-совместимым API, облачный или локальный.
