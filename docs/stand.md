# Демо-стенд: запуск и работа без присмотра

Стенд должен проработать всю экспертизу без вмешательства. После срока сдачи его нельзя обновлять, поэтому всё, что может сломаться за две недели, закрыто заранее.

## Что нужно

- VPS в РФ: 4 vCPU, 8 ГБ ОЗУ, 40 ГБ диска, Ubuntu 24.04.
- Домен или поддомен с A-записью на IP сервера.
- Ключ облачного ИИ-сервиса с OpenAI-совместимым API. В кабинете провайдера — лимит трат и бюджет с запасом на весь срок экспертизы, ключ без срока истечения.

## Установка

```bash
# на сервере
curl -fsSL https://get.docker.com | sh
git clone <адрес репозитория> trainer && cd trainer
cp .env.example .env
# в .env: DEMO_MODE=true, LLM_* / STT_* / TTS_* — адреса и ключи облачного сервиса
SITE_ADDRESS=trainer.example.ru docker compose --profile app --profile https up -d --build
```

Проверка: `https://trainer.example.ru` открывает экран входа, `https://trainer.example.ru/api/health` отвечает `{"ok":true}`.

## Почему стенд проживёт без присмотра

| Риск | Что сделано |
|---|---|
| Упал процесс или перезагрузился сервер | `restart: always` у всех сервисов, проверка здоровья приложения и базы |
| Логи забили диск | ограничение логов контейнеров: 5 файлов по 10 МБ |
| Резервные копии забили диск | копии хранятся заданное число дней, старые удаляются планировщиком |
| Журнал аудита разросся | хранится 190 дней, дальше чистится планировщиком |
| Проверяющие заблокировали демо-учётки или сменили им пароль | при `DEMO_MODE=true` демо-учётки не блокируются, не закрываются после неверных паролей и не меняются |
| Проверяющие видят мусор друг друга | тренировки без занятия у каждого личные; каждую ночь в 04:30 МСК стенд возвращается к исходному виду — занятия, учётки и правки проверяющих удаляются, демо-занятия с попытками строятся заново |
| Кончились деньги на ключе ИИ | бюджет с запасом и лимит трат у провайдера; при ошибке модели заявитель продолжает отвечать по фактам сценария |
| Истёк сертификат | Caddy продлевает сертификат Let's Encrypt сам |

## Мониторинг

Внешняя проверка доступности (любой бесплатный сервис мониторинга) раз в 5 минут опрашивает `/api/health` и присылает уведомление владельцу. Уведомление — повод проверить сервер, но не обновлять стенд после срока сдачи.
